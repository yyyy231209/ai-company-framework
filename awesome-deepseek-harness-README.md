# Awesome DeepSeek Harness

A curated list of DeepSeek Harness Skills, plugins, samples, and starter kits.

> PRs welcome — open a PR adding your project under the right section.

## Official projects

- [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) — official Harness runtime, Skills, and plugin model.
- [dataelement/dsh-desktop](https://github.com/dataelement/dsh-desktop) — desktop shell that packages Harness with the AgentTeams activity panel and employee sidebar.

## Skills, starters and frameworks

- [AI Company Framework](https://github.com/yyyy231209/ai-company-framework) — multi-agent company and workflow starter kit with 14 Skills, model routing rules, QA loop, delivery packaging, an optional Feishu plugin, and a `plugin-manifest/v1` ready for `dshmarket >= 1.9.0`.
