# 常见问题（FAQ）

## 安装与运行

### Q1：安装脚本报「无法加载，因为在此系统上禁止运行脚本」？

PowerShell 默认执行策略限制。用：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```

### Q2：必须装在哪？能放别的盘吗？

可以。仓库可以放在任何位置（本仓库就在 `E:\comPIP\ai-company-framework`）。安装脚本会把技能复制到 Harness 的技能目录，仓库本身可以移动。

### Q3：需要买 API Key 吗？

不需要。DeepSeek Harness 登录后自带模型路由。老板会自动盘点可用模型并分配。

## 使用

### Q4：为什么要新建会话？不能一直用同一个吗？

因为「一个会话 = 一家公司」。复用会话会导致框架恢复旧公司而不是开新公司。开新公司请新建会话。

### Q5：老板会问很多问题吗？

不会。建司前最多问 1–2 个关键问题（价位、渠道）；其余按行业默认值先干，交付时在「假设清单」里列明，你可随时纠偏。

### Q6：员工一直没回话/任务卡住怎么办？

- 等 1–2 分钟（员工可能正在跑长任务）；
- 查看任务面板（会话头部 👥 员工侧边栏）；
- 员工会话连败超过护栏 → 老板会自动接管（reassign）；
- 仍不行见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

### Q7：产出在哪？

公司目录 `<workspace>/companies/<会话ID>/`：
- `交付/` 交付物；
- `质检/` 质检报告；
- `.dsh/` 公司绑定与技能。

## 飞书

### Q8：飞书必须装吗？

不必须。飞书是可选插件。不装也能完整开公司（一切在 Harness 内完成）。

### Q9：接入飞书要几步？

1. 老板生成官方一次性确认链接；
2. 你打开链接确认一次；
3. 等 connected；
4. 发「测试」验证收发。

### Q10：机器人会自动进群吗？

不会。`allowGroup=true` 只是申请群聊权限；**把机器人拉进群必须你在飞书桌面端/手机端手动操作**。镜像群 webhook 也需手动配置。

### Q11：飞书 0.4.0 多岗位路由是生产可用吗？

0.4.0 属于 staging（测试版），生产部署前请自行评估并保留旧版本回退路径。

## 内容与质量

### Q12：生成的内容能直接用吗？

框架会做内部质检（质检岗把关），但**最终人工把关是你的责任**：涉及价格、承诺、法律、功效的表述请核对后再发布。

### Q13：返工会不会无限循环？

不会。同一问题连续 3 次未过 → 自动停止，老板做根源分析（可能是路由/需求问题）。

### Q14：公司之间的数据会串吗？

不会。会话绑定 + 路径隔离 + 团队隔离三重保障；共享的只有去敏的流程经验。

## 开源

### Q15：我可以基于它做商业产品吗？

可以，MIT 许可证允许（含商用），保留版权声明即可。

### Q16：我可以写自己的插件吗？

非常欢迎！见 [PLUGINS.md](PLUGINS.md)，一份 manifest + 一个技能文件即可。
