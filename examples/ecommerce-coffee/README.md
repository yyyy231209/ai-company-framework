# 示例公司：精品咖啡豆电商（ecommerce-coffee）

一个「复制即用」的示例公司。新建会话后把下面这句话直接发给老板，框架会按本模板开公司。

## 一句话开司模板

> 我要开一家卖精品咖啡豆的电商公司，首单产出一篇小红书种草笔记和一套客服话术包，价格带 60–200 元，主渠道小红书，需要老板机器人和客服机器人接入飞书（P2P 即可，暂不需要群聊）。

## 岗位清单（本模板将触发）

| 岗位 | 预置技能 | 模型档位（框架自动盘点后分配） |
|------|----------|----------------|
| 文案 writer | role-writer | 批处理档（flash） |
| 客服 customer-service | role-customer-service | 批处理档（flash） |
| 质检 qa | role-qa | 强推理档（pro） |

> 飞书插件为可选：示例里声明需要，则老板会引导接入；不需要就删掉那句话。

## 首单任务图（框架自动创建）

```text
t1 开业小红书种草笔记（writer）        ┐ 并行
t2 客服话术包（customer-service）      ┘
t3 质检 文案+话术包（qa，依赖 t1,t2）
t4 交付打包（老板）
```

## 期望产出（公司目录内）

```text
<companyRoot>/
├─ 交付/文案/小红书笔记_开业.md
├─ 交付/客服/客服话术包.md
├─ 交付/交付包.md
├─ 质检/质检报告.md
└─ .dsh/skills/{writer,customer-service,qa}.md
```

## 如何跑

1. Harness 新建会话；
2. 复制上方「一句话开司模板」并发送；
3. 回答老板最多 1–2 个问题（如已给全则不问）；
4. 等待建司/入职/任务/质检/交付。

## 切换成你自己的业务

把模板里的业务词替换即可：行业、首单交付物、价位、渠道。岗位搭配会自动变化（见 docs/ARCHITECTURE.md 的行业模板库）。
