# 示例公司：现代家具电商（ecommerce-furniture）

第二个示例：展示框架的 **DIY 扩展性**——换一句话，岗位搭配自动变成家具行业版本。

## 一句话开司模板

> 我要开一家卖现代简约家具的电商公司（餐桌/沙发/床/收纳），首单产出一份市场与竞品筹备底稿，目标平台淘宝+小红书，价格带 1000–8000 元，需要老板机器人和客服机器人接入飞书。

## 岗位清单（本模板将触发）

| 岗位 | 预置技能 | 说明 |
|------|----------|------|
| 选品采购 product-picker | 自建（行业模板） | 市场/竞品/供应商筹备，禁止编造数据 |
| 视觉陈列 visual-merchandiser | 自建（行业模板） | 商品视觉与图片验收 |
| 商品文案 writer | role-writer | 详情页/种草文案 |
| 运营投放 ops | role-ops | 平台发布与投放 |
| 客户服务 customer-service | role-customer-service | 飞书客服直连客户 |
| 财务 finance | role-finance | 成本测算/毛利核算（可选） |
| 质检 qa | role-qa | 全流程把关 |

> 对比第一个示例（咖啡电商 3 岗），这里触发 7 岗——**同一框架，不同行业，岗位自动变化**。这就是卖点 4「DIY 各种公司」。

## 与咖啡示例的差异点

| 维度 | 咖啡电商 | 家具电商 |
|------|----------|----------|
| 岗位数 | 3（文案/客服/质检） | 7（选品/视觉/文案/运营/客服/财务/质检） |
| 首单 | 种草笔记+话术包 | 市场与竞品筹备底稿 |
| 特殊岗位 | 无 | 选品采购 + 视觉陈列（行业特有） |
| 渠道 | 小红书 | 淘宝 + 小红书 |

## 复用方式

- 拷贝本目录为 `examples/ecommerce-<你的品类>/`；
- 改 README 里的一句话模板（品类/首单/价位/渠道）；
- 新会话发送，即可复现。

## 生产验证备注（2026-08）

家具行业曾在新会话实测：7 岗建司 + 飞书双机器人（老板/客服）全部接通；期间发现并修复了飞书权限默认全开、禁止重复授权、老板回传通道、客服重建联动 4 个问题（见 CHANGELOG v0.1.1）。
