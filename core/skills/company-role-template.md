# 岗位技能模板（骨架由老板下发，完整技能由员工自己写）

> **门控**：本模板仅在公司模式开启（`company_mode`=on）的会话中用于岗位骨架/技能；未开启的会话不得使用。

> **分工**：老板只写「骨架」= 岗位英文名 + 一句话职责 + 输入/输出文件契约 + 模型路由 + **记忆模式**。**员工入职时按本模板把自己的完整技能写全并持续维护**——员工最懂自己的活。
> **铁律**：接口契约（输入/输出文件名）由老板定，员工不可擅自改；技能内容（怎么做）员工自己写、自己更新。
> **记忆模式**：老板定骨架时必填 `记忆模式` 字段——**三层**（对客岗：客服/销售/商务/客户经理，入职配 `company-customer-memory`，读客户档案+公司+通用记忆）；**单层**（内部岗/老板：普通对话 + feishu-logs 留痕，不配客户档案）。

```markdown
---

记忆模式: <三层 | 单层>   # 三层=对客岗（配 company-customer-memory，客户档案+公司+通用记忆）；单层=内部岗（普通对话+feishu-logs 留痕）
---
```

## 填写要点（老板注意）

1. **输入输出契约要具体到文件名**——员工之间靠文件交接，契约模糊=返工。
2. **验收标准可勾选**——验收员工照单打钩，不放水。
3. **工具纪律写"并行"**——批量活一条消息并行调用，别逐条。
4. **岗位模型路由单独告知用户**（视觉岗→视觉模型；批处理岗→快速模型；慢活岗→便宜模型）。
5. 每个岗位技能末尾追加「经验库」段：
   - 入职/任务前读 `<dshHome>/company-wisdom/<岗位>.md`
   - 任务后把 ≤3 行工作流程经验写进汇报（老板代存）
   - 铁律：只写流程经验，严禁业务敏感内容
